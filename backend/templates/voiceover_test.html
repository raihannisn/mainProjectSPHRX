SPHEREx Voice-over Test

Halaman uji terpisah untuk mengirim naskah yang disediakan backend ke Gemini TTS. API key tetap berada di backend dan tidak dikirim ke browser.

Menjalankan demo lokal

Atur GEMINI_API_KEY di environment backend, jalankan uvicorn main:app --reload --port 8000 dari folder backend, lalu buka http://localhost:8000/voiceover-test. Jangan menaruh API key di halaman ini atau commit ke Git.
