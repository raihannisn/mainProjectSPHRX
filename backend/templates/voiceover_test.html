SPHEREx Voice-over Test

A standalone test page for sending backend-provided scripts to Gemini TTS. The API key remains on the backend and is never sent to the browser.

Voice: Mission Liaison (Kore)

Run the local demo

Set GEMINI_API_KEY in the backend environment, run uvicorn main:app --reload --port 8000 from the backend folder, then open http://localhost:8000/voiceover-test. Do not put the API key on this page or commit it to Git.
